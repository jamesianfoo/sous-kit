# 08 String rotation (loops over strings)

Two lowercase words are given, one per line. Print 1 if the second is a right rotation of the first (write the word in a circle and start reading from any letter), otherwise print -1.

Example
```
sample
plesam
```
Output: 1

Note: for this problem the starter template's number parsing will not apply. Read lines[0] and lines[1] as strings.

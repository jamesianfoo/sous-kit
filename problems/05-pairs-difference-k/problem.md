# 05 Pairs with difference K (Pattern B, duplicates matter)

Print the number of pairs (i, j) with i < j whose values differ by exactly K. Duplicates form separate pairs. K can be 0.

Input: line 1 is N, line 2 is N integers, line 3 is K.

Example
```
6
10 15 23 14 2 15
13
```
Output: 3  ((10,23), (15,2), (15,2))

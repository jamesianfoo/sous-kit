# Code-Practice-Test

Practice pack for HSBC / SHL / AMCAT style coding assessments.

- Start with `LEARN.md` for the method.
- Copy `templates/template.js` at the start of every real question.
- Drill the problems in `problems/` in order. Run `./run.sh 01` to test your answer.
- Reference answers live in `solutions/`. Run `./run.sh 01 sol` to see them pass.

Requires Node.js.

# sous-kit rules

- No colour, spacing or font-size literals in `src/components` or `src/screens`. Every value is a token via `var()`.
- New tokens go in `tokens/tokens.jsonc`. Never edit `src/styles/tokens.css`; it is generated by `npm run tokens`.
- Interactive elements are `<button>` or `<a>`. Never a `div` with `onClick`.
- Every component ships with all states: default, hover, focus-visible, disabled, and any status variants.
- Run `npm run lint:tokens` before saying a change is done. If it fails, fix the component, not the lint.
- Only touch files named in the task. Run the build before saying it passed.
